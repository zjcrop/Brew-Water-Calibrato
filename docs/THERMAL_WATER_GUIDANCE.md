# 单次加热、水质变化与LuckyBean冲煮建议

检索及实现日期：2026-11-15。范围按用户要求限定为：新配水从初始状态单次加热到目标冲煮温度后使用。未对用户实际配方、壶具或豆批做实液实验。

## 钙不会在某个通用温度突然失效

“永久硬度”是非碳酸盐硬度的传统称呼，并不是钙离子的耐热身份。普通水加热主要讨论碳酸钙析出；这属于暂时硬度相关现象，不是加热生成永久硬度。不能设置60、80、90或100°C作为所有配方共同的起析点。

[USGS硬度定义及分析方法](https://pubs.usgs.gov/wsp/1454/report.pdf)区分碳酸盐与非碳酸盐硬度。[USGS水硬度说明](https://www.usgs.gov/water-science-school/science/hardness-water)确认加热可能形成碳酸钙沉积。钙来自CaCl₂也不代表混合后永不析出：离子溶解后会与其他盐提供的碳酸体系一起参与平衡。[2023原始试验](https://www.jstage.jst.go.jp/article/fstr/29/6/29_FSTR-D-23-00059/_html/-char/en)使用CaCl₂与NaHCO₃配制硬水，说明必须看完整混合水；其气液交换条件不能直接标定咖啡配方失钙率。

无机碳酸体系的简化反应为：

Ca²⁺ + 2HCO₃⁻ ⇌ CaCO₃(s) + CO₂(g) + H₂O

真实结果还取决于pH、Ca、碱度、CO₂交换、升温路径、热壁、旧垢、晶核及有机配体。升温改变平衡和速率，过饱和也不等于立即析出某个百分比。有机柠檬酸盐、乳酸盐的络合与酸碱物种未求解，不能用当前离子账本精确预测热后游离钙。

| 原始证据 | 对单次加热有何意义 | 外推边界 |
|---|---|---|
| [Tang等2021，CCPP计算研究](https://www.mdpi.com/2073-4441/13/1/42) | 在10–90°C及不同CO₂边界下，沉淀潜力取决于完整物种和边界条件。 | 平衡潜力不是实际电壶短时失钙量。 |
| [Al-Gailani等2020，模拟电壶原始试验](https://eprints.whiterose.ac.uk/id/eprint/158884/1/Inorganic_Mineral.pdf) | 即使同样加热到沸，不同升温路径仍有不同结果；热后取样/冷却也影响终点。 | 高硬度试验水不能换算为萃离配方的失钙比例。 |
| [Al-Gailani等2021，传热表面结垢试验](https://eprints.whiterose.ac.uk/id/eprint/172371/3/Al-Gailani%20et%20al.%20first%20revision%20%28clean%20version%29.pdf) | 壁面状态和温度参与结垢。 | 壶显示温度不等于热壁温度，不据此生成固定析出阈值。 |

[USGS碱度FAQ](https://or.water.usgs.gov/alk/faq.html)区分CO₂交换与沉淀：CO₂逸出本身会改变pH，但不单独改变总碱度；CaCO₃实际沉淀才同时移除Ca和碱度。在只考虑该反应时，每沉淀1 mol CaCO₃去掉1 mol溶解Ca及2当量碱度。因此不能由pH上升或电导下降单独反推失钙。

## 对单次加热的实际建议

1. 先沿用当前豆批/LuckyBean方案要求的注水温度，新配水加热到该温度后使用。没有实测差异时，不为“保钙”强行降低温度。
2. 一次加热也可能同时发生蒸发浓缩和析出，不能默认热后所有离子都下降。实测蒸发损失5%时，非反应溶质的体积账本倍率为1/0.95≈1.0526；这不是Ca/Mg/HCO₃热后浓度预测。水质量比较要排除取样、倒出和补水损失。
3. 若出现浑浊或沉积，记录并检验实际使用水；看不见也不能证明零变化。不要在未知失钙量上盲目补加钙盐。
4. 热后GH、碱度与投料计算结果分开保存；仅成对前后实测才给差值。GH包含Ca和Mg，差值不能单独归因为Ca损失。

## 不自动转成“低温、短萃”

[Batali等2020原始感官研究](https://doi.org/10.1038/s41598-020-73341-4)（[作者公开全文](https://escholarship.org/content/qt7200z8cg/qt7200z8cg.pdf)）比较滴滤87、90、93°C，并通过调整其他冲煮变量控制TDS和萃取率EY。总体温度效应未达显著（MANOVA p=0.11），TDS/EY影响更明显；个别属性仍有较小差异。结果限于所测咖啡、滴滤和温区，不能解读为温度永远无效。

降温若要保持原来的浓度和萃取率，可能需要更细研磨或更长接触；没有依据因为理论结垢就同时降低温度、缩短萃取。该论文[2021作者更正](https://www.nature.com/articles/s41598-021-82505-9)将配水单位从“每升”改为“每100升”；后续不可直接复用未更正PDF的盐量，避免100倍错误。更正不是感官结果撤回。

[2020滴滤分段研究](https://doi.org/10.1002/jsfa.10323)说明不同时间段的浓度与感官属性并非简单“越久越苦”。[2024全浸泡研究](https://doi.org/10.1038/s41598-024-69867-6)中热萃组起始92°C、随后置于室温，不能冒充92°C恒温60分钟，更不能搬成手冲最佳时长。

LuckyBean处理规则：先固定单次加热用水，再以该豆批已有方案为基线，通过杯测和杯中TDS/EY决定下一步。若试温度，可比较基线±2°C，一轮只改一个变量；±2°C是可执行的小步试验，不是论文证明的最佳步长。滴滤流完时间由研磨、滤纸、注水和床层共同产生，不能和浸泡可独立设置的接触时间混同。

## 本版软件怎样表达

- 新模块仅做single-heating记录与操作提示，不计算起析温度、实际失钙率、pH、LSI或永久硬度增加量。
- 加热前离子仍按实际显示投料核算；热后未知浓度为null，不能把计算值冒充热后检测。
- 可选记录最高温度、蒸发、可见沉积、同方法前后GH和总碱度。
- 水记录导出保留稳定water字段，并新增concentrationBasis与heatingAssessment。总滴定碱度、实测TDS、pH未测时仍未知。
- LuckyBean只显示本地用水建议，不因未验证的失钙假设自动改变权威冲煮步骤、温度、时长或方案指纹。

## 后续实液校准

同一批配水分装，设未加热参照与单次加热到87、90、93、96°C等样本；温度点是试验设计，不是安全边界。固定水量、壶具、升温路径与到温后取样流程，记录水质量与实际注水温度。同方法检测Ca/Mg、碱度及测量温度下pH；可补浊度和过滤/未过滤对照。室温冷却后测得的是该取样流程后的样品，不是注水瞬间的热水实测。

EC/TDS只能作变化线索，不能区分钙沉淀、其他离子浓缩及温度补偿。只有实液数据才能回答“这套配方单次加热后实际变化多少”，再进一步拟合并独立验证模型。目前代码和浏览器验证不等同于完成这些实验。
