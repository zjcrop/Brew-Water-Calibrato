# 萃离 2.8.0 升级说明

本版保留暗色界面、水滴首页、四页导航、咖啡/茶预设、半有机与无机配方，以及原有实验盐和硅路线。重点是统一计算、明确调整语义，并让称量值与结果一致。

## 计算变化

- 网页实际调用共享非负配方求解核心；补钙与补缓冲不再重复使用同一份盐。
- 缺少钠盐时，可用钾碳酸氢盐承担实际HCO₃目标；无可用盐时显示未满足目标。
- 分开显示HCO₃、GH与碳酸盐碱度贡献；有机盐和硅源未建模的酸碱作用明确说明。
- 按盐水合物、批次纯度、实际水量计算；推荐量按天平分辨率取整后重新核算。
- 不再把经验系数呈现成真实结合、游离或沉淀百分比；TDS为可选仪表系数下的电导参考。
- 对外数据提取完整的修订咖啡参数与六类茶预设，保留跨项目业务字段含义。

## 微调与提示

- 固定总量联动：改变一盐的指定比例，其余盐按比例让量；结果、偏差和警示立即更新。
- 独立调量：改变指定盐每5L投加目标；配方水保持其他盐克数，固定批量母粉按新配比重新换算。
- 风味控制保留200点预算，超出时其他项按比例让量，界面说明发生的变化；提供触屏步进按钮。
- 当前不投加的盐仍可恢复；提供重置微调。
- 盐源不足、称量精度不足、离子偏差、浓度筛查提醒与无效输入可见，不用“正常”掩盖缺失或错误。

## 称量与混合

按防潮处理组安排称量顺序：相对稳定的先称，明显吸湿/潮解的后称快封；同组按实际称量质量从大到小。未测堆积密度时不推算粉体体积。称量编号不替代混合顺序，少量组分仍需几何递增混匀；每次取用母粉前充分混匀。

## 亲水气相SiO₂粉体

保留用户确认的亲水食品添加剂身份，支持99.999999%标称纯度；区分抗结配比与水中名义SiO₂投料。提供0、0.5、1、2、5mg/L工程对照档；量化后显示实际产品量、名义浓度与最终母粉百分比，不推算真实溶解率或顺滑增益。抗结先测0.5%母粉；若专测口感，采用0/1/2mg/L重复盲测，1mg/L是试验起点而非已证实的有效剂量。详见SILICA_REVIEW.md。

## 本地使用与构建

需要Node.js 22及以上。仓库根目录运行：

```text
npm ci
npm run check
npm run prepare:web
npm run preview
```

浏览器打开 http://127.0.0.1:8768/ 。本版使用本地ES模块，网页应通过HTTP服务器或Android应用加载；不要直接双击index.html。

Android构建仍使用仓库中的GitHub Actions。版本号同步为2.8.0/versionCode 20800，Android工作流会校验核心后打包。只有实际运行成功后才会产生APK；网页测试不能替代Android设备验收。

## 证据与未完成的实验

计算回归、发布物校验及浏览器交互检查的记录见验证报告。原料实液稳定性、滴定与杯测尚需按 [研究与验证矩阵](SCIENCE_AND_VALIDATION_v2.8.md) 执行。豆型预设是已有研究与经验起点，不代表当前豆批的实测酸谱，也没有一个经本轮实验确认的通用最佳配方。
