# 萃离 v2.8：研究依据、计算口径与验证要求

核验日期：2026-11-15。本文记录软件的可计算范围和证据边界，不把代码通过测试视为杯测或实液验证。

## 保留已有研究与设计

原项目的 `COFFEE_WATER_AUDIT.md` 已包含半有机盐、乳酸盐、钾钠等碱度再平衡、按豆型设置目标和降低花香端硫酸镁驱动。盐库也已有柠檬酸钙、镁、钠、钾。这些构思继续保留；本次升级修正的是计算一致性和说明方式，不将这些已有工作重新包装为新发现。

品牌配料表能证明市场上采用某种盐或调节路径，不能证明该盐在本软件剂量下优于其他盐，更不能由未公开的配料表反推商业配方精确比例。例：Third Wave Water官方公开不同烘焙型的盐组成，但未公开各盐准确质量。[品牌原始资料](https://support.thirdwavewater.com/en-US/what-is-in-third-wave-water-76575)

## v2.8计算语义

1. **投料到名义离子组成：** `浓度mg/L = 投料g × 有效纯度 ÷ 盐摩尔质量 × 化学计量数 × 离子摩尔质量 × 1000 ÷ 最终体积L`。结晶水计入盐摩尔质量，不作为新增溶质离子；采用化学式、水合物与批次纯度必须一致。
2. **GH：** `2.497×Ca + 4.118×Mg`，Ca/Mg单位mg/L，结果以mg/L CaCO₃计。该换算亦见[美国EPA附录](https://www.epa.gov/sites/production/files/2021-01/documents/2021_msgp_-_appendix_j_-_calculating_hardness.pdf)。它是总钙镁的当量指标，不等于游离金属比例或实际结垢率。
3. **碳酸盐碱度贡献：** `50.043 × (HCO₃/61.017 + 2×CO₃/60.008)`，结果以mg/L CaCO₃计。输入为投料化学计量贡献，未求解溶液中HCO₃/CO₃物种重分布；有机盐、硅酸盐等的完整酸中和贡献不由该式覆盖。
4. **总滴定碱度：** 需带终点/方法的实测值或充分定义的平衡模型。不能以固定 `alkEq=0.5/1.5` 使各种柠檬酸盐等效为HCO₃；也不能在未测时填零。USGS区分不同滴定方法并要求明确报告口径。[方法说明](https://or.water.usgs.gov/alk/methods.html)、[报告口径](https://or.water.usgs.gov/alk/reporting.html)
5. **质量和电导：** 投料质量、离子质量和、电导估计、TDS笔换算值分别保存。TDS笔系数若未知，不将固定0.50假定成该仪表的实际系数。水合水、活度、络合及实际溶解状况仍造成模型偏差。
6. **求解与残差：** 所选盐对所有目标离子同时受约束；不把同一柠檬酸钙分别补钙和补缓冲后再盲目叠加。缺少可满足目标的盐时输出残差和不能满足的目标，不以零或“正常”冒充成功。
7. **称量后的组成：** 按天平分辨率量化后重新核算离子和残差。局部微调只改变指定盐；如果提供固定总质量的配比调整，必须作为独立模式明确告知。
8. **风味和风险：** 保留豆型工程起点与杯测方向，不承诺“镁必定提香”“钙必定增甜”。缺少条件时，pH、游离离子比例、络合百分比及沉淀百分比均未知。经验提示不得呈现成测得的概率或平衡计算结果。

对于跨项目字段 `alkalinityMgLAsCaCO3`，不得把本版仅计算的碳酸盐贡献静默冒充总滴定碱度。推荐并列保留明确命名的碳酸盐贡献与带来源的实测值；缺失字段不代表零。

## 原料规格与称量顺序

软件操作顺序采用“相对稳定的较大用量先称，明显吸湿/潮解盐后称、快封”。这是减少暴露与便于操作的原则，不是盐间相容性或保存期保证。

| 原料 | 已核验的处理信息 | 软件说明建议与来源 |
|---|---|---|
| 无水CaCl₂ | 吸湿、可潮解；吸水会改变实际有效含量。 | 标为后称、快封；[USDA 2024技术报告](https://www.ams.usda.gov/sites/default/files/media/2024TechnicalReportCalciumChlorideHandling.pdf)。 |
| MgCl₂·6H₂O | 官方评估描述为很易潮解的晶体/片状物。 | 标为后称、快封；[EFSA 2019原始评估](https://efsa.onlinelibrary.wiley.com/doi/10.2903/j.efsa.2019.5751)。 |
| 无水MgSO₄ | 厂商TDS标吸湿。 | 标为后称、快封；[Scharlab TDS](https://www.scharlabchina.com/documents/TDS/MA0080_TDS_EN.pdf)。 |
| MgSO₄·7H₂O | 不能仅因已含结晶水就标“不吸湿”。 | 仍按包装/SDS防潮，水合物换算独立于吸湿分级；[Thermo Fisher SDS](https://assets.thermofisher.com/DirectWebViewer/private/document.aspx?prd=ALFAA11596~~PDF~~MTR~~CGV4~~EN~~2025-09-13+20%3A36%3A45~~Magnesium+sulfate+heptahydrate~~)。 |
| KHCO₃ | OIV描述为略吸湿。 | 可列相对先称组，但不叫“绝不吸湿”；[OIV原始条目](https://www.oiv.int/index.php/de/node/3866)。 |
| NaHCO₃ | 厂商SDS要求避潮，并标吸湿。 | 可列相对先称组，开瓶后仍防潮；[Thermo Fisher SDS](https://assets.thermofisher.com/DirectWebViewer/private/document.aspx?prd=ACR44710~~PDF~~MTR~~CLP1~~EE~~2023-10-07+10%3A38%3A36~~Sodium+bicarbonate~~)。 |
| 乳酸钙五水合物 | 食品添加剂SDS同时列吸湿与风化性质。 | 不作为“不易潮”的绝对稳定载体；[Kishida SDS](https://www.kishida.co.jp/product/catalog/msds/id/2434/code/010-13635e.pdf)。 |
| 乳酸镁、钙镁柠檬酸盐、葡萄糖酸盐 | 本轮未找到适用于用户批次、可比较吸湿速度的资料。 | 以COA/SDS与实际包装状态为准；未知不填“低风险”。 |

含水状态和水合物名应明确。例如570.49 g/mol为柠檬酸钙四水合物，[PubChem原始条目](https://pubchem.ncbi.nlm.nih.gov/compound/Calcium-citrate-tetrahydrate)可核验；乳酸镁二水合物按[USP FCC](https://doi.usp.org/USPFCC/FCC_F101978_03_01.html)为238.47 g/mol。旧238.44相差约0.013%，可以统一，但不属于主要误差来源。

“用量占比大”可由当前配方质量计算；“松装体积大”需该批次粉体的松装密度；晶体真密度不等于松装密度。没有测量时只按质量/占比排序，不虚造体积或把所有品牌粉体当成同一堆积状态。

**称量顺序与混合顺序分开。** 可先分别称好并盖好容器，再混合；少量组分仍需通过几何递增混合获得均匀度，而不是把“最后称”理解为“整份最后直接倒在大粉堆上”。低溶解度盐、长期母液、干粉分层与吸湿后的效价，都要独立验证。

## 验证矩阵与验收边界

| 层次 | 必须验证的内容 | 结果能证明什么 |
|---|---|---|
| 静态数据 | MAT化学式/水合物/纯度、PROFILE审核覆盖、全部茶型、导出与页面一致；拒绝可执行字面量 | 数据与发布链一致，不能证明风味 |
| 算术与求解 | 手算参考量、体积缩放、质量与电荷账本、盐源缺失、跨组盐、防除零/空值、不可满足目标 | 名义配方计算正确，不能证明真实溶解 |
| 量化与界面 | 当前天平步长；推荐用量重新计算；残差、未知值与错误可见；微调语义 | 用户拿到的称量数与所显示水质一致 |
| 实液 | 记录盐批号/含水规格/原水；测温度、pH、GH与滴定方法；观察即时、加热、24h/7d沉淀 | 该批次/条件下的配制与保存表现 |
| 感官 | 同豆批、同冲煮、同温度，随机编码、独立重复；碱度梯度、等GH钙镁比较、前/后加盐对照 | 判断该实验范围的差别与喜好，不自动产生通用最佳水 |

感官记录应包括豆批、处理法、烘焙/养豆日期、粉水比、研磨、时间和温度；有条件时记录杯中pH、滴定酸度和分析酸谱。不能把前期文献均值当作这一批豆的实测数据。

本文件中的实液与感官项目是后续验证要求，不是已完成实验。自动化测试报告由本次实际运行记录提供。
